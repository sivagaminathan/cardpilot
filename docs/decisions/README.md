# Architecture Decision Records (ADRs)

This directory contains records of significant architectural and technical decisions made for CardPilot.

## ADR Format

Each ADR is stored in Markdown using the naming convention `NNNN-title.md`:

- **Title:** Short, descriptive title.
- **Status:** Draft, Accepted, Superseded, or Rejected.
- **Date:** YYYY-MM-DD.
- **Context:** Problem statement, forces, and constraints.
- **Decision:** The specific architectural choice made.
- **Consequences:** Positive and negative trade-offs, follow-up actions.
